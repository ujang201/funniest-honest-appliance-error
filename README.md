# The Funniest Honest Appliance Error

One line of at most 200 characters: the funniest honest error message an appliance could show. A washing machine reports an unbalanced load — one sock has taken the drum hostage and refuses to negotiate — in its own flat, put-upon voice.

## Run

```sh
node main.ts
```

Writes the entry line to `/output/entry.txt`. Deterministic: the same line on every run, no randomness, no network.

## Entry

> ERROR 47: Unbalanced load. One sock has taken the drum hostage and refuses to negotiate. I will not spin until the hostage is freed.
